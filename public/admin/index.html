Ординаторская

Ключи API, цепочка моделей и лимиты. Ключи хранятся на сервере и в браузер не возвращаются, видно только маску.

Ключи API

Ключ из админки перекрывает переменную окружения. Самый надёжный вариант: переменная окружения в Netlify, тогда здесь можно ничего не вводить.

Цепочка врачей

Идут по порядку. Если первый упал или не ответил, зовётся следующий. Провайдеры без ключа пропускаются. Модель обязана понимать картинки. Кнопка «Тест» проверяет ключ, имя модели и effort (без картинки).

    При смене адреса ключ «Свой» стирается, чтобы старый ключ не ушёл на новый сервер.
